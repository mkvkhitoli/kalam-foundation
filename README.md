# Kalam Foundation website (multi-page)

## Files
- index.html     Home (banner, photo slider, short about, 3 programs, upcoming events)
- about.html     Story, mission, team
- programs.html  All programs
- events.html    Events + photo gallery
- donate.html    UPI + bank details
- contact.html   Volunteer form + contact details
- style.css      Design for ALL pages (colours, fonts, layout)
- main.js        Slider, menu highlight, copy-UPI button
- images/        Put your photos here (slide1.jpg ... slide4.jpg, etc.)

## Editing
Yellow-highlighted text (class="ph") is placeholder: replace it and delete class="ph".
The header menu and footer are repeated in every page. If you change them, change all 6 pages.
Cloudflare serves clean links automatically: about.html opens as kalamfoundationkhitoli.in/about

# Kalam Foundation website

## Easy updates (admin page)
Go to https://app.pagescms.org, sign in with GitHub, open kalam-foundation.
You can edit: Home slider, Numbers & highlights, Events (upcoming & past), Photo gallery.
Click Save — the website updates in 1–2 minutes.

Content lives in the content/ folder (JSON). Photos live in images/.
Other text (About, Programs, Support, Contact): edit the .html files on GitHub.
Colours: top of style.css. Settings for the admin page: .pages.yml
